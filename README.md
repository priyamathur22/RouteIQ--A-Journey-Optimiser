# RouteIQ - A Journey Optimiser

**RouteIQ** is an intuitive web application that helps users plan their journeys efficiently by suggesting optimized routes between cities based on distance, budget, and travel preferences. Designed with a clean interface, interactive forms, and a dynamic map view, it enhances the travel planning experience.

---

## Features

- **Optimized Routes:** Quickly find the best routes between your start and destination cities.
- **Budget-Friendly Planning:** Set your travel budget and get route suggestions accordingly.
- **Interactive Map:** Visualize selected routes directly on the map.
- **Responsive Design:** Works seamlessly on desktops, tablets, and mobile devices.
- **User-Friendly Interface:** Easy-to-use forms and interactive cards for quick selections.
- **Loading & Progress Indicators:** Smooth feedback during route calculations.

---

## How to Use

1. Clone the repository:

   ```bash
   git clone https://github.com/priyamathur22/RouteIQ--A-Journey-Optimiser.git

2. Open the project folder in VS Code (or any IDE).

3. Open index.html in your browser.

4. Select your start and destination cities.

5. Set your budget and explore the optimized routes.

6. Interact with the map to visualize selected routes and details.

Tech Stack
1.Frontend: HTML, CSS, JavaScript

2.Libraries/Frameworks: None (Vanilla JS)

3.Map Integration: Leaflet.js or custom map implementation
